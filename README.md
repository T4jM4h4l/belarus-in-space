# 🚀 Беларусь в космосе — Медиа-инсталляция

Интерактивная медиа-инсталляция, рассказывающая о вкладе Беларуси в освоение космоса.

## 📋 О проекте

Полноэкранная презентация с аудио-рассказчиком, которая включает:

- **Вступление** — введение в историю
- **Космонавты** — белорусские космонавты
- **Учёные** — учёные, внесшие вклад в космическую программу
- **Невидимый фронт** — инженеры и технические специалисты
- **Итоги** — заключение

## 🛠 Стек технологий

- **React 19** + **TypeScript**
- **Vite 7** — сборка и разработка
- **Tailwind CSS 3** — стилизация
- **Framer Motion** — анимации
- **Lucide Icons** — иконки
- **shadcn/ui** — UI компоненты

## 🚀 Запуск

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Сборка для продакшена

```bash
npm run build
```

Результат появится в папке `dist/`.

### Предпросмотр продакшен-сборки

```bash
npm run preview
```

### Линтинг

```bash
npm run lint
```

## 🎮 Функционал

### Основной сайт
- Полный скролл по всем секциям
- Плавающая кнопка "🎧 Презентация" в правом нижнем углу

### Режим презентации
- Полноэкранный режим с по-слайдовой навигацией
- Автоматическое воспроизведение аудио для каждого слайда
- Управление аудио: 🔊 пауза/воспроизведение
- Навигация: Далее / Назад / Esc
- Прогресс-бар вверху
